# Design Reference Guide - LeadForgeAI

## 1. Aesthetic References

### 1.1. Spline References
- 3D interactive dashboards with glass panels.
- Floating particles surrounding UI widgets.
- Orbit camera angles centering on database nodes.

### 1.2. Equinox / Deltha Screenshots
- Ambient neon glows reflecting from buttons.
- Oscillating status indicators.

### 1.3. Persian Architectural Geometry
- Symmetric grid boundaries.
- Rounded pointer outlines.
- Dark theme backgrounds contrasted with Persian turquoise.

## 2. Animation Ideas & Timelines
- **Tab Change**: R3F Camera pans back, rotating slowly before focusing on the new viewport.
- **Auditing Progress**: 3D mesh scales out, throwing neon blue particle waves outwards.
- **Card Hover**: Custom GSAP ease-out scale and drop shadow intensity glow.
